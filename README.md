# Array Calculator

A Python-based array calculator using NumPy for fast, dynamic operations on arrays.

## Description
Perform addition, subtraction, multiplication, and division on arrays with continuous user interaction.

## Features
- Dynamic operations on arrays
- Continuous input loop
- Error handling (invalid input, division by zero)
- Efficient NumPy usage

## Tech Used
- Python
- NumPy

## 🚀 How to Use 

Follow these steps to run the Array Calculator:

1. Click **"Remix this app"** to create your own copy.
2. Click **"Add tools"** and add the **Console**.
3. Again click **"Add tools"** and add **Files**.
4. In the Files panel, find and open **array calculator.py** (or your main file).
5. Click the **Run** button at the top.
6. Use the calculator in the console by following the prompts.
