# Array Calculator

A Python-based array calculator using NumPy for fast, dynamic operations on arrays.

## Description
Perform addition, subtraction, multiplication, and division on arrays with continuous user interaction.

## Features
- Dynamic operations on arrays
- Continuous input loop
- Error handling (invalid input, division by zero)
- Efficient NumPy usage

## Tech Used
- Python
- NumPy

## How to Run
1. Install NumPy:
   pip install numpy
2. Run the script:
   python filename.py
